# Proposal — Build TonMay Studio OS v1

## Problem
Anton needs one simple, cohesive workspace to run TonMay Productions: managing clients, bookings, production prep, shot lists, communication, payments, footage organization, deliverables, and follow-up without requiring technical tooling or jargon.

## Commercial Outcome
Create a professional studio operating system that:
- Reduces missed appointments and simplifies client scheduling.
- Thoroughly prepares clients for video/photo sessions.
- Streamlines production organization (shot lists, interview guides, footage tagging).
- Speeds up client communication and review cycles.
- Tracks deposits, remaining balances, and payment statuses cleanly.
- Establishes standardized footage ingestion and archiving workflows.
- Prepares TonMay Productions to scale client volume without administrative overhead.

## First Proof Case
**ASC3ND Collective — Community Cuts for Kids**.
The first client will exercise the end-to-end workflow (inquiry, booking, shot lists, internal Macs collaboration, client portal isolation, reminder dry-runs, footage planning, and deliverable delivery).
